Export your trades from TradeSea

Roundturn reads TradeSea's list of filled orders and pairs them into trades. TradeSea exports the list one page at a time, so a session usually takes a few files. Choose them all together in Roundturn and they are read as one import.

Times
The time zone in the file

  1. In TradeSea

    Open Orders and select Filled

    Open the Orders list for the account and select the Filled view. The export saves what the list shows, so in the Filled view the file holds only filled orders, with no cancelled or rejected ones.

  2. In TradeSea

    Export, then export every page

    Export the list. TradeSea shows 10 orders a page and its export saves only the page on screen, so go to the next page and export again, until every page of the session is saved. Do it one right after another, while nothing new is filling.

    Every page

    A missing page means missing orders. Roundturn warns you when a file looks like a single page, and when the orders end with a position still open. Exporting a page twice does no harm: an order on two pages counts once.

  3. In Roundturn

    Choose TradeSea: Orders (Filled), then all the files

    On the Import page, choose the Roundturn account the trades belong to, then Choose files.

  4. In Roundturn

    Check the preview, then import

    The preview says what was read and lists anything to check before you import.

Good to know

  • One account per export. Export each TradeSea account on its own and import it into its own Roundturn account. If you copy trades, the same orders can go into several accounts; the preview points it out.
  • Times are read in the time zone the file names (PST, EST and so on), not your CSV time zone setting. That setting is used only for a time whose zone is missing, and the preview says so.
  • Commissions come from each account's own commission setting, not from the file, so every import is charged the same way.
  • A position still open at the end of the files is kept until a later import closes it.
  • Forgot a page? Add files in the preview adds it to the same import.

If the preview says

"This looks like one page of TradeSea's list."
A single file with exactly 10 orders is probably one page of several. If you had more than 10 filled orders, export the other pages and add them.
"These orders end with 1 NQ long still open"
If you were flat, the export left out an order: show the whole session in TradeSea's Orders list and export every page again. If you really are still in the trade, import it now and its exit later.
"These look like files from Tradovate, not TradeSea."
The files are from another platform. The preview offers to read them as that platform.
