How an import works

  1. Choose the account

    On the Import page, choose the Roundturn account the trades belong to, or add one with + New account. One import goes into one account.

  2. Choose files

    Choose files asks where the trades are from, reminds you what to export, then opens your computer's file window. You can also drop the files on the page: Roundturn tells the platform from the file.

  3. Read the preview

    The preview counts what is new and what was already imported, and lists anything to check: a missing page, a position still open, a commission that differs from your setting.

  4. Import

    Import saves the new trades. Every import can be undone from the import history on the same page.

Good to know

  • The same file twice adds nothing twice. Rows already imported are left alone, and only new ones are added.
  • Fees come from each account's own commission setting, charged on every trade, not from the file. The preview compares the two and offers to use the file's rate.
  • Times: each guide says which time zone its file is read in.
  • Size: one import can be up to 10 MB.
